One one-star review written by a house cat about its human: the food bowl sat empty for four whole minutes, the human laughed at the screaming, and the cat has since moved his favourite mug to the floor. Permanently. `main.ts` validates the review (single line, 1–200 characters, printable ASCII, opens as a one-star review) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
